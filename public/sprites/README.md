# sprites

`player.png` — the player character, a small barefoot halfling, seen from
behind; `player-front.png` — the same, from the front, shown while he walks
towards the camera. Both on transparent backgrounds and the same size.
Generated by `tools/player-sprite.html`; open it in a browser, pick an outfit
and tone, and save both downloads here.

Loaded by `src/scene/player.js` as an upright card facing the camera. The
sprite is scaled so it appears `PROPS.playerHeight` (1.15 m) tall on screen,
and its width is taken from the image's own aspect ratio, so any dimensions work
as long as the character fills the frame vertically and stands on the bottom
edge — that edge is the pivot that meets the ground.
